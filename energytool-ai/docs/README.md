# Документы для передачи решения команде

| Документ | Для кого и зачем |
| --- | --- |
| ../README.md | Всем: состав решения, быстрый старт и границы готовности |
| SETUP.md | Разработчикам: установка, конфигурация, запуск без прежнего project |
| ARCHITECTURE.md | RAG и backend: база, поток обработки, модули, связь с пунктами 1–3 |
| INTEGRATION.md | Коллегам по пунктам 4–8: API, сессии, статусы, заявка и задачи интеграции |
| TESTING.md | QA: команды, результаты, ограничения измерений и критерии проверки |
| PRESENTATION.md | Авторам презентации: корректные тезисы и порядок демонстрации |
| PACKAGING_CHECK.md | Результаты проверки переносимости именно этой копии |
| reference/ | Исходные PDF/DOCX организаторов и разрешённые зависимости |
| reports/ | Исторические отчёты о доработке, версиях и измерениях |
| ../bot_checks/ | Вопросы, многоходовые сценарии и методика оценки |

Для рабочего прототипа 1–3 нужны код, база, requirements, пример окружения
и инструкция запуска. Для передачи остальной команде нужны также архитектура,
контракт интеграции и результаты тестов. Презентация и полный прототип кейса
не заменяются этими документами: пункты 4–8 команда завершает отдельно.

Отчёты reports описывают прежние прогоны и могут ссылаться на пути исходного
project. Полные старые логи сессий в репозиторий не переносились. Актуальные
пути и команды этой копии указаны в документах выше.
