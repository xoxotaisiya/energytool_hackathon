# Приложение EnergyTool

Это единственная актуальная реализация ядра в данном репозитории.
Начните с [корневой инструкции](../../README.md) и
[контракта интеграции](../../docs/INTEGRATION.md).

Рабочая директория Python — эта папка. Запуск: `.venv/Scripts/python.exe main.py`.
Конфигурация: `.env`, созданный из `.env.example`, либо переменные окружения.
