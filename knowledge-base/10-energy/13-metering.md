# Приборы учёта и системы сбора данных

## Зачем предприятию может понадобиться изменить учёт

В материалах EnergyTool выделены три основные причины: 1. Требования к
учёту: для отдельных категорий потребителей обязателен почасовой
интервальный учёт. 2. Ценовая категория: для третьей--шестой категорий
нужны интервальные почасовые данные; для второй категории требуется
двухтарифный зонный учёт. 3. Управление потреблением: месячные показания
не позволяют увидеть почасовые пики и особенности профиля нагрузки.

## Виды учёта

  ---------------------------------------------------------------------
  Вид учёта                          Для чего используется
  ---------------------------------- ----------------------------------
  Однотарифный                       Одна цена за киловатт-час без
                                     деления по времени

  Двухтарифный зонный                Разделение показаний по зонам
                                     суток

  Интервальный почасовой             Данные по временным интервалам;
                                     необходим для третьей--шестой
                                     ценовых категорий
  ---------------------------------------------------------------------

Почасовой интервальный учёт обязателен для потребителей с присоединённой
мощностью от 670 кВт.

## Интеллектуальные системы учёта

В материалах EnergyTool к минимальному набору функций интеллектуальных
систем учёта отнесены: - удалённый сбор показаний; - фиксация параметров
качества электроэнергии; - журнал событий; - доступ потребителя к своим
данным.

## Параметры, указанные в документах на прибор

В материалах упоминаются тип прибора, класс точности и год поверки.
Конкретные модели, подробные профили и каналы связи в предоставленных
материалах не подтверждены. Подбор конкретной модели или проектирование
схемы подключения требует специалиста.
